Pavo，让设置壁纸变简单。

浏览多个地区的 Bing 每日壁纸，收藏喜欢的图片，下载原图，或直接设为桌面。Pavo 免费、开源，安静地完成这些日常操作。

下载 Pavo 在 GitHub 查看

macOS / Windows · 以 Releases 页面为准

你可以做的事

把找壁纸、保存壁纸和换壁纸放在一个简单的桌面应用里。

浏览不同地区
查看多个地区每天提供的 Bing 壁纸，在同一处切换和浏览。
收藏与下载
保存喜欢的图片，需要时下载原图，也可以直接设为当前桌面。
离线继续查看
已缓存的内容无需联网也能打开，常用操作还可从系统托盘进入。
按你的环境显示
选择浅色、深色或跟随系统主题，让界面适应当前桌面。

自动轮换设置

设定一次，让桌面在之后按你选择的节奏更新。

切换间隔
10 分钟至 24 小时 从短暂变化到一天一次，按使用节奏选择。
轮换方式
顺序或随机 决定下一张壁纸的选择方式。
日常使用
后台运行与系统托盘 让自动轮换持续工作，需要时再打开 Pavo。

从下一张壁纸开始。
